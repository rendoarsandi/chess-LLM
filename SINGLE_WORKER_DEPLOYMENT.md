# Single Cloudflare Worker Fullstack Deployment

Panduan deployment aplikasi Chess LLM sebagai **single Cloudflare Worker** yang menjalankan frontend (Next.js) dan backend (API) dalam satu deployment.

## 🎯 Arsitektur

Project ini menggunakan **@cloudflare/next-on-pages** untuk deploy Next.js sebagai Cloudflare Worker:

```
┌───────────────────────────────────────┐
│   Single Cloudflare Worker           │
│   (chess-ai.rendoarsandi.workers.dev) │
├───────────────────────────────────────┤
│                                       │
│  ┌─────────────────────────────────┐ │
│  │  Next.js Frontend               │ │
│  │  - Pages (/, /game, etc)        │ │
│  │  - Static Assets                │ │
│  │  - Server Components            │ │
│  └─────────────────────────────────┘ │
│                                       │
│  ┌─────────────────────────────────┐ │
│  │  API Backend                    │ │
│  │  - /api/game/{id}/* endpoints   │ │
│  │  - Durable Objects (GameDO)     │ │
│  │  - D1 Database                  │ │
│  │  - KV Storage                   │ │
│  │  - Gemini AI Integration        │ │
│  └─────────────────────────────────┘ │
│                                       │
└───────────────────────────────────────┘
```

## 📦 Prerequisites

- Node.js 20+
- Cloudflare account
- Wrangler CLI installed
- Gemini API key

## 🚀 Quick Start

### 1. Install Dependencies

```bash
npm install --legacy-peer-deps
```

**Note**: `--legacy-peer-deps` diperlukan karena @cloudflare/next-on-pages belum support Next.js 15.5.4 (support sampai 15.5.2).

### 2. Setup Cloudflare Resources

Jika belum setup database dan KV:

```bash
# Login
wrangler login

# Create D1 database
wrangler d1 create chess-llm-db

# Update wrangler.toml dengan database_id

# Run migrations
wrangler d1 migrations apply chess-llm-db

# Create KV namespace
wrangler kv:namespace create "OPENINGS_KV"

# Update wrangler.toml dengan KV id

# Set secret
wrangler secret put GEMINI_API_KEY
```

### 3. Build & Deploy

**Single command untuk build dan deploy:**

```bash
npm run deploy
```

Ini akan:
1. Build Next.js dengan @cloudflare/next-on-pages
2. Generate worker-compatible output di `.vercel/output/static`
3. Deploy ke Cloudflare Workers

**Atau step-by-step:**

```bash
# Build saja
npm run build

# Deploy saja (setelah build)
wrangler deploy
```

## 🛠️ How It Works

### Build Process

1. **`npm run build:next`** menjalankan `@cloudflare/next-on-pages`
   - Builds Next.js app
   - Converts output ke worker-compatible format
   - Generates `.vercel/output/static/_worker.js`

2. **Worker Entry Point** (`worker/src/fullstack-worker.ts`):
   - Check if request is API (`/api/game/*`)
     - YES → Route to GameDO (existing backend logic)
     - NO → Route to Next.js worker (frontend pages)

### Request Flow

```
User Request
    ↓
Cloudflare Worker
    ↓
    ├─ Is /api/game/* ?
    │   ├─ YES → GameDO → D1/KV → Gemini AI → Response
    │   └─ NO  → Next.js Worker → Render Page → Response
    ↓
User receives response
```

## 🐛 Troubleshooting

### Error: "Cannot find module .vercel/output/static/_worker.js"

**Penyebab**: Belum run build

**Solusi**:
```bash
npm run build
```

### Error: "ERESOLVE unable to resolve dependency tree"

**Penyebab**: Next.js version conflict dengan next-on-pages

**Solusi**: Install dengan `--legacy-peer-deps`:
```bash
npm install --legacy-peer-deps
```

### Warning: "@cloudflare/next-on-pages deprecated"

**Info**: @cloudflare/next-on-pages akan deprecated, rekomendasi pakai [OpenNext](https://opennext.js.org/cloudflare).

**Untuk sekarang**: Masih bisa digunakan dengan baik.

**Future**: Migrasi ke OpenNext adapter (akan lebih optimal).

### API Routes Tidak Work di Local Dev

**Penyebab**: `npm run dev` hanya jalankan Next.js dev server, tidak termasuk Worker.

**Solusi**: Gunakan `npm run preview` untuk testing fullstack.

### Build Success tapi Deploy Gagal

**Debug steps**:

1. Check build output:
```bash
ls -la .vercel/output/static/
```

2. Test locally:
```bash
npm run preview
```

3. Check wrangler logs:
```bash
wrangler tail
```

## ⚡ Performance

### Advantages

✅ **Single deployment** - No need to manage multiple services
✅ **Edge computing** - Runs on Cloudflare's global network
✅ **Low latency** - Both frontend and backend at the edge
✅ **Integrated** - Frontend and backend share same environment
✅ **Cost effective** - Single Worker instance

### Considerations

⚠️ **Worker size limit** - Max 1MB (free) / 10MB (paid)
⚠️ **CPU time limit** - Max 50ms (free) / 30s (paid)
⚠️ **Next.js features** - Some features may not be supported

## 🚨 Important Notes

1. **Next.js Version**: Currently using 15.5.4, but next-on-pages supports up to 15.5.2. Works with `--legacy-peer-deps`.

2. **Build Output**: `.vercel` folder contains generated worker code. Already in `.gitignore`.

3. **API Routes**: DO NOT create API routes in `app/api/`. Use Worker routes instead (already configured in `worker/src/fullstack-worker.ts`).

4. **Durable Objects**: Already configured and working. Game state persists across requests.

5. **Database**: D1 migrations already applied. Check with:
   ```bash
   wrangler d1 execute chess-llm-db --command "SELECT * FROM games LIMIT 5"
   ```
